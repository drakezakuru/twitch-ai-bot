## Детально: що було на кожній відсутній вкладці

### ❌ chat — Чат з налаштуваннями AI
- Налаштування AI генерації (system prompt, temperature)
- Контекстні джерела (відео, стрімер, пам'ять)
- Авто-чат (логіка відповідей)
- Персона + стиль відповідей

### ❌ logs — Live логи
- WebSocket live логи (chat, AI, system)
- Фільтрація по типу подій
- Експорт логів

### ❌ patterns — Паттерни відповідей
- CRUD паттернів (name, system_prompt, style, language, max_length)
- Варіанти промптів (A/B testing)
- Активація/деактивація паттернів

### ❌ personas — Характери (вкладка)
- Список характерів (personas)
- CRUD характеристик
- Активація/деактивація

### ❌ promptpool — Пул промптів
- Список промптів
- Масовий імпорт
- Випадковий вибір на день
- Вимкнення/вмикання промптів

### ❌ triggers — Триггери
- CRUD тригерів (keyword + response)
- AI/фіксовані відповіді
- Вимкнення/вмикання

### ❌ events — Події Twitch
- Реакції на події (follow, sub, raid, cheer, points)
- Налаштування шансу
- AI/фіксовані відповіді

### ❌ banlist — Чорний список
- Додавання/видалення користувачів
- Блокування повідомлень

### ❌ wordfilter — Фільтр слів
- Блокування/заміна слів
- Режими (block/replace/warn)

### ❌ chatai — Налаштування AI чату
- System prompt редактор
- Temperature, max length
- Використання персони
- Авто-чат (логіка самостійних повідомлень)

### ❌ memory — Пам'ять користувачів
- Факти per-user
- Лічильник повідомлень
- Останнє бачення

### ❌ scheduled — Заплановані повідомлення
- CRUD запланованих повідомлень
- Мін/макс інтервал
- AI/фіксовані

### ❌ graphs — Графіки
- Активність per-bot
- Графік повідомлень

### ❌ highlights — Виділення
- Останнє повідомлення бота
- Виділення повідомлень чату

### ❌ engagement — Залученість
- Метрики per-відповідь
- Support, mentions, replies, breakthrough
- A/B testing engagement

### ❌ compare — Порівняння ботів

### ❌ actionlog — Лог дій
- Історія дій в панелі

### ❌ ai — AI налаштування (окрема вкладка)

## v10 функції, які НЕ реалізовані в v12

1. **Улюблені вкладки** (favorites) — drag-and-drop порядок вкладок
2. **Mobile sidebar** — повноцінний мобільний сайдбар з ховером
3. **Темна/світла тема** — в v12 є, але не всі кольори
4. **Звуки сповіщень** — playNotificationSound()
5. **Гарячі клавіші** — Ctrl+K є, але не всі
6. **Сортування списків** — drag-and-drop для паттернів/тригерів
7. **Масові дії** — bulk delete/update
8. **Імпорт/експорт** — JSON імпорт/експорт конфігурацій
9. **Віджети (повний список)** — 22 віджета з URL
10. **A/B тестування** — UI для порівняння промптів
11. **RAG по VOD** — пошук по транскрипціях
12. **Telegram сповіщення** — налаштування нотифікацій
13. **Live Vision** — "що бачить бот"
14. **Спостереження** — повний UI для observation mode
