# Защита секретов панели

Глобального переключателя, раскрывающего или скрывающего чувствительные данные, нет.
Токены, пароли и API-ключи всегда вводятся через password-поля; API не возвращает
их значения, а безопасные статусы используют только маски.

OBS Window Capture и Display Capture настраиваются пользователем. Панель не может
гарантировать, что окно или системные уведомления не попадут в захват; перед эфиром
проверьте сцену OBS.

OBS Blur Guard — Browser Source с непрозрачной защитной маской. Плотность 100%
полностью закрывает пиксели сцены под маской; постоянные зоны всегда непрозрачны.
Browser Source физически не может применить gaussian blur к пикселям другого OBS
source. Если нужен именно blur, добавьте фильтр размытия к захватываемому source
или общей group в OBS.

В карточке Blur Guard доступны три режима: цветная маска, загруженная пользователем
картинка и настоящий OBS blur-фильтр. Для третьего режима сначала добавьте фильтр
к нужному source/group в OBS, затем укажите в панели точные имена source/group и
фильтра. Приложение включает его через OBS WebSocket. Адрес и пароль задаются
локально через `OBS_WEBSOCKET_URL` и `OBS_WEBSOCKET_PASSWORD`; пароль не попадает
в API. Область настоящего blur задаётся настройками самого OBS-фильтра.
