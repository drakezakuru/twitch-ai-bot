## 1. Ядро модерации (Moderation Engine)

- [x] Таблица `moderation_rules`: {id, account_id, channel ('' = все), name, category
  (custom|insult|hate|threat|sexual|spam|links|caps|repeat), pattern (слово/regex),
  action (replace|block|timeout|log), severity (1-5), enabled, lang, created_at}.
- [x] Таблица `moderation_events`: {id, account_id, channel, username, rule_id, severity,
  action_taken, message_excerpt, created_at} — журнал нарушений.
- [x] Модуль `app/moderation.py`: `check_message(account_id, channel, username, text) ->
  list[Verdict]`; Verdict: {rule, action, severity, masked_text}.
- [x] Встроенные словари RU/EN/UA по категориям (insult/hate/threat/sexual) — файлы
  `app/moderation_dicts/ru.txt` и т.п., построчные, комменты с `#`; подключаются как
  правила с category и дефолтной severity.
- [x] Частичная замена (replace): оскорбления → `***` с сохранением длины; серьёзные
  (hate/threat/sexual) → не публиковать ответ бота вовсе (для исходящих) или
  помечать для стримера (для входящих).
- [x] Порогseverity: 1-2 = replace, 3 = block, 4-5 = block + timeout (если §3.4 включён).
- [x] Пользовательские правила имеют приоритет над встроенными (порядок применения:
  custom → built-in; первый вердикт с action ≠ log останавливает).
- [x] Режимы работы: `off` / `log_only` / `replace` / `full` — per-account, per-channel
  override через channel_overrides. Включается одним переключателем «Автомодерация»,
  без выбора технических режимов (владелец явно просил «включить без ручного выбора
  технического режима» → дефолт `full` при включении).
