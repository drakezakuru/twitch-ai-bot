# Приватность панели на стриме

Режим **«Скрыть чувствительное»** в шапке маскирует видимые токены, пароли, API-ключи и URL виджетов. Состояние сохраняется между переходами и перезапусками страницы; по умолчанию скрытие включено. Раскрывайте и копируйте секреты только осознанно.

OBS Window Capture и Display Capture настраиваются пользователем. Панель не может гарантировать, что окно или системные уведомления не попадут в захват; перед эфиром проверьте сцену OBS.
