### A1 (баг, подтверждён кодом): «Ошибка загрузки: Method Not Allowed» на вкладках бота
- **Суть**: у `GET /api/accounts/{id}` роута НЕТ — только PUT/DELETE (routes.py:208,232).
  Два жертвы: `loadBrainPreview` (09_brain_p3.js — вкладка «Мозг бота» бота;
  **уже переведён на `_allBots`**) и `loadBotGeneral` (03_bots.js:523 — вкладка
  «Общие»: **поля бота не заполняются**, `_currentBot` перезаписывается ошибкой 405,
  nickname/proxy/token_masked пустые).
- **Фикс (S)**: вариант (а) — GET-роут в routes.py: `SELECT * FROM accounts WHERE id`
  → `_account_to_dict` (+`token_masked`, без токена); вариант (б) — JS берёт бота из
  `_allBots`. Рекомендация (а): надёжнее, чем полагаться на порядок загрузки списка.
- **Защита**: Ф1-тест усилен до метод-уровня (путь+HTTP-метод) — этот класс теперь
  ловится автоматом; вызов в allowlist `_API_CALLS_WITHOUT_BACKEND` до фикса.

### A2 (баг UX): вечное «Загрузка...» в Аналитике
- Оценки ответов / Heatmap / Сообщения за 24ч / Топ чатеров остаются на «Загрузка...»,
  когда данных нет или ручка упала. Плюс: до рестарта панели init-цепочка была мертва
  (Ф2-1) — после рестарта+Ctrl+Shift+R autoload ожил.
- **Фикс (S)**: во всех хендлерах аналитики — empty-state («Данных пока нет — как
  накопится, появится») вместо вечно висящей «Загрузка...».

### A3 (баг UX): стрим-инструменты показываются не-модератору
- Карточка с формой рендерится всегда; не-модератор видит «Этот бот не модератор —
  недоступно» и мёртвую форму под ней. **Фикс (S)**: скрывать форму целиком, оставлять
  одну строку «доступно только роли модератор».

### A4 (проверка): Twitch API «Проверить подключение»
- Владелец несколько раз сомневается, работает ли. Сделать честный вывод ошибки
  (шаг: сеть / 401 / неверный client_id), ответ в тосте + строка-лог; проверить на
  изолированном инстансе (без кредов — на качество сообщения об ошибке), доложить
  владельцу: «работает/не работает и почему».

### A5 (решение Q&A → C11): beep/запикивание не на месте + «не работает»
