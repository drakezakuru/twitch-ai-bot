## Проблемы, зависимости и ограничения

- Реальный ElevenLabs Voice Clone требует действующий API key, интернет и доступ к API.
- XTTS/Coqui/F5-TTS требуют тяжёлых optional-пакетов, места на диске и желательно GPU; без них должны работать Piper/Web Speech.
- Ollama offline-режим требует установленный Ollama и скачанные модели.
- Twitch требует Client ID, Client Secret и действующий OAuth/token.
- Полный browser smoke test требует установленного headless-браузера и драйвера.
- Некоторые внешние API могут менять формат, лимиты, цены или доступность.
- Vision blur не гарантирует стопроцентное распознавание; нужен ручной override и безопасный fallback.
- Предсказание события «на сколько секунд заранее» возможно только эвристически и не должно считаться гарантией.
- Голосовые клоны нельзя создавать или использовать без согласия владельца голоса.
- Хранение кадров, аудио и chat logs требует контроля размера, retention и доступа.
- Нельзя отправлять кадры наружу при включённом локальном режиме.
- Existing worktree содержит пользовательские изменения и удаления; перед чисткой нужно составить список и получить отдельное подтверждение на удаление.
- Целевая автоматизация не должна означать бесконтрольное самообучение: постоянные изменения требуют approval, истории и rollback.
