AI и провайдеры

🧠 AI (глобально)

Vision — модель, которая смотрит картинки стрима. Подсказки: OpenRouter → google/gemini-2.0-flash:free · Ollama (локально, бесплатно) → llava или minicpm-v (установить: ollama pull llava) · именованный провайдер (🧩) → его модель с поддержкой картинок.

🧩 Кастомные провайдеры

Свои API-провайдеры (OpenAI-совместимые): дайте имя, укажите Base URL и ключ, добавьте модели кнопкой «＋ Модель». Потом выберите их в «AI Провайдер» выше и в настройках каждого бота.

Один список моделей: пометьте каждую как чат, vision или обе. Модель не добавляется дважды — не нужно вписывать её отдельно для vision.

🟣 Twitch API

Что это даёт панели:

  • Вход ботов через Twitch (кнопка «Войти через Twitch» без ручного токена)
  • Информация о каналах: игра, название стрима, зрители

Без этих ключей панель работает, но перечисленные функции недоступны. Создайте приложение на dev.twitch.tv/console → Apps → New Application и вставьте Client ID и Client Secret сюда.

❓ FAQ
Как добавить бота?

Раздел «Боты» → «+ Добавить бота» → введите ник и OAuth-токен (twitchtokengenerator.com)

Как настроить разное поведение в разных каналах?

Боты → Настроить → Каналы → Per-channel overrides. Выберите канал и задайте юмор/сарказм отдельно для него.

Как настроить TTS?

Раздел «Настройки» → «🔊 TTS» → выберите провайдер. Для OBS: скопируйте URL виджета и добавьте как Browser Source.

Как работает фильтр внимания?

Боты → Настроить → Внимание. Бот собирает сообщения в батч в течение N секунд, фильтрует шум (+1, KEKW) и генерирует один ответ.

Как добавить бота без ручного токена?

В форме добавления бота нажмите «🟣 Войти через Twitch»: откройте twitch.tv/activate, введите код — бот добавится сам. Нужен Twitch API (Client ID/Secret) в настройках; без них — ручной токен с twitchtokengenerator.com.

Как бот узнаёт стримера?

Боты → Настроить → «👤 О стримере»: заполните профиль (био, стиль, интересы) и загрузите фото для распознавания в кадре. Включите автообновление — AI сам дополнит профиль из чата.

Что бот видит и слышит со стрима?

Stream Vision: бот периодически смотрит кадры стрима и слушает аудио (Whisper-транскрипция). Vision-модель задаётся в AI-настройках. Локально и бесплатно — Ollama: установите модель llava или minicpm-v и выберите её как Vision-модель.

Как запускать ботов на разных API/моделях?

Боты → Настроить → Обзор → AI Override: выберите свой провайдер, модель для текста и vision, свой API-ключ. Без override бот использует глобальные настройки.

Бот включён, но не подключён — что делать?

Карточка бота показывает health-индикатор: жёлтый «Подключается», красный «Ошибка» с причиной и временем. При ошибке нажмите «↻ Переподключить». Частые причины: неверный OAuth-токен, истёкший токен, недоступен Twitch (проверьте прокси).

Как откатить действие в панели?

Настройки → «🕘 Журнал действий». У записей с кнопкой «↩ Отменить» действие можно откатить (например, удаление созданного бота). Если кнопки нет — откат недоступен, запись только для информации.

Где смотреть логи бота?

Боты → Настроить → Дополнительно → Логи: фильтры по уровню/категории, экспорт CSV. Общий поток — Настройки → «📋 Глобальные логи». Логи появляются, когда боты читают чат и отвечают.

Как сделать резервную копию?

Настройки → «💾 Резервная копия»: скачайте архив (включая .env) и при необходимости восстановите кнопкой «Восстановить». Текущие данные будут перезаписаны.

Как защитить панель паролем?

На localhost пароль не нужен. Для явного доступа из LAN/сети задайте PANEL_AUTH_USER, PANEL_AUTH_PASS и TOKEN_ENCRYPTION_KEY; без полного набора панель остаётся на 127.0.0.1.

Как подключить виджеты в OBS?

Вкладка «Виджеты» → заполните контент в формах → скопируйте URL виджета → в OBS добавьте Browser Source с этим URL. Фон прозрачный. Все файлы виджетов лежат в папке widgets/ — их можно править без панели (см. widgets/README.md).
