            🛡 Автомодерация
            
Выключена

        

        
Бот отслеживает токсичность и спам в чате: оскорбления маскируются, серьёзные нарушения блокируются, угрозы всегда пишутся в журнал. Таймауты — только если включены явно.

        
ℹ️ Автомодерация работает на словарях (moderation_dicts/) и ваших правилах: без ИИ. ИИ-анализ сообщений — это соседняя вкладка «Анализатор»; Vision-модель (вкладка AI) — отдельная опция для картинок/названий. Оба не требуются для работы автомодерации.

        

            

            Включить автомодерацию (режим full)
            
        

        

            

            Модерация может таймаутить через Twitch (600с, severity 4-5)
            
        

        

            

            Слушать сообщения через EventSub (нужны права модератора)

            🎙 Голосовое управление
            
        

        
Команды берутся из локального stream audio → Whisper и исполняются только после совпадения фразы активации и голоса владельца.

        

            

                
                
                Профиль и команды изолированы по выбранному боту и каналу.
            

            

                
                
                Команда без этой фразы всегда игнорируется.
            

            

                
                
                Низкая уверенность создаёт предложение модератору, но ничего не меняет сама.
            

            

                
                

                    

                    
                

                Необратимые TTS, Soundboard, clip и moderation не входят в голосовой whitelist.
            

        

        

        

            Регистрация голоса владельца
            
Прочитайте вслух: «Я подтверждаю локальное голосовое управление этим каналом. Таймер старт, таймер пауза, цель плюс пять. Мой голос используется только для проверки владельца».

            
Запись хранится локально в data/voice-control и не отправляется AI-провайдеру. Модель проверки загружается отдельно, аудио остаётся на этом компьютере.

            

                
                
                
                
                
            

            
        


        

            

                Предложения с низкой уверенностью
                
            

            

            
Хоткеи панели работают только при открытой вкладке. OBS не умеет вызывать API этих биндингов напрямую; его hotkeys управляют сценой/source, поэтому отдельная фиктивная интеграция не добавлена.
