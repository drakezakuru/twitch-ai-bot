🎙 TTS за баллы канала

Зритель тратит баллы канала на награду-активацию (например «Озвучить сообщение») — его текст озвучивается в OBS через TTS-движок бота. Создай награду в Twitch → Creator Dashboard → Rewards. Названия через запятую; пусто = озвучивать ЛЮБУЮ награду с текстом. Требуется включённый TTS-движок.

👀 Зритель покупает награду «Озвучить сообщение» за 100 баллов и пишет текст — в OBS его текст произносится голосом бота.

Пустой выбор использует голос TTS бота.

💬 TTS-чат (озвучки) /widget/tts-chat-overlay

🎧 Заказ песен (Song Request) /widget/song-request

Зрители командой !sr <ссылка или название> добавляют трек в логическую очередь.

🛡 Защита сцены (Blur Guard) /obs/blur-guard-v2

Защитная маска поверх сцены в OBS: при срабатывании AI она закрывает контент. Browser Source не умеет размывать другие OBS-источники; для настоящего blur используй OBS-фильтр на source/group. 100% полностью скрывает пиксели.

📍 Блюр по зонам (всегда 100%) beta · blur-guard-v2

Блюрить не весь экран, а выбранные области (код, поле пароля) — они закрыты ПОСТОЯННО, без «ослабления». Формат: x,y,w,h через точку с запятой; можно px или проценты (например 25%,40%). Координаты — левый верхний угол зоны.

🔧 Как менять виджеты без панели

Публичные API виджетов не требуют авторизации — ими можно управлять из OBS-хоткея, Home Assistant, Streamer.bot или curl. Админ-API требует auth-сессию панели.

curl http://localhost:8000/api/widgets/public/goals                # цели
curl http://localhost:8000/api/widgets/public/counter/death       # счётчик
curl http://localhost:8000/api/widgets/public/now-playing         # сейчас играет
curl http://localhost:8000/api/widgets/public/top-donator/alltime # топ донатеров

# счётчик +1 (как чат-команда !death):
curl -X POST http://localhost:8000/api/widgets/counters/death/increment \
  -H "Content-Type: application/json" -d '{"value":"1"}'

# донат из внешнего сервиса (двигает челлендж/топ/recent):
curl -X POST http://localhost:8000/api/widgets/public/donation-webhook \
  -H "Content-Type: application/json" \
  -d '{"username":"nick","amount":100,"message":"го!"}'
⭐ Избранный чат /widget/selected-chat

Общий список доверенных пользователей фильтрует настоящий Twitch-чат. Список можно редактировать после импорта.

По одному логину в строке или через запятую; @ добавлять необязательно.

Импорт требует broadcaster OAuth с moderation:read или channel:read:vips; существующие логины сохраняются.

Ноль секунд оставляет сообщения до заполнения лимита; история ограничивается количеством и временем.
