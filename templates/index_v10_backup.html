📺 Источник стрима

По умолчанию бот качает HLS-плейлист Twitch (задержка 3-7 сек). Переключи на OBS или своё ffmpeg-устройство — задержка падает до 0-500 мс.
💡 В OBS нажми «Запустить виртуальную камеру». На Windows точное имя устройства можно получить так: ffmpeg -list_devices true -f dshow -i dummy
♻️ Vision-cache (семантическая дедупликация описаний)
Если новое описание ≥ N% совпадает с предыдущим — пропускаем дублирующие комментарии в чат. Экономит шум при «застывшей» сцене.

👁️ Vision-промпт и анализ кадра

🧹 Срезать chain-of-thought из vision-ответа
«We need to respond… Let's parse…» от reasoning-моделей (nemotron-reasoning, o1, deepseek-r1) обрезается. Оставляет только финальный русский ответ.
📰 Подмешивать Helix-контекст (название стрима + игра)
Бот сообщает vision-модели «это RAW! Cup, категория CS2» — модель не выдумывает название игры из шрифтов на майке. Требует Twitch Client ID/Secret.

🎙️ Диаризация — различать голоса

Загрузка…
Что нужно для WhisperX-режима:
  1. Установить пакет: pip install whisperx (~500MB зависимостей вместе с torch/pyannote).
  2. Получить HF-токен на huggingface.co/settings/tokens (read-доступа достаточно).
  3. Принять условия модели на pyannote/speaker-diarization-3.1 и pyannote/segmentation-3.0 (нажать «Agree»).
Если что-то не выполнено — бот автоматически откатится на heuristic.

🧪 Тестовый прогон

Ручной одноразовый прогон — хватает один кадр или ~15с аудио с указанного канала и прогоняет через AI/Whisper. Канал должен быть онлайн.

🥷 Anti-detection, Bio Persona и Smart-trigger v10.4.4


                
                

                    
                    

                        
🥷 Anti-detection (маскировка под человека)

                        
Включает суб-фичи ниже. По дефолту: задержки + проверка повторений + игнор других ботов. Опечатки выключены (включай осознанно).

                        

                            

                                
                                Имитация «печатания» (gaussian-задержка)
                            

                            

                                
                                Не повторять себя (Jaccard на последние N своих сообщений)
                            

                            

                                
                                ⚠️ Опечатки (опасно, по дефолту OFF)
                            

                            

                                
                                Не отвечать другим ботам

🟣 Twitch приложение (Client ID / Secret)

        

            Раньше эти значения нужно было прописывать в .env.
            Теперь их можно задать прямо здесь — сохраняется в БД и применяется без рестарта.
            Если оставить пустыми, используются значения из .env.
        


        


        

            

                
                
                
Публичный ID приложения. Получить на dev.twitch.tv/console/apps.

            

            

                
                

                    
                    
                

                
Для Device Code Flow secret не нужен — только для авто-refresh OAuth-токенов.

            

        

        

            
            
        

        
Что включается, когда Client ID задан: вход через Twitch (Device Code Flow), контекст канала в AI-промпте, EventSub. Если задан и Client Secret — ещё и авто-refresh токенов.

    


    
    

        
🔒 Безопасность и интеграции (опционально)

        
Эти возможности включаются переменными в .env или (для Client ID/Secret) выше через UI. Здесь можно увидеть текущий статус и управлять авто-обновлением токенов.


        


        

            
            ↻ Авто-обновление OAuth-токенов в фоне (Feature 2)
        

        
Требует Client ID и Client Secret (см. блок выше или .env). Каждые 10 мин проверяет, истекают ли токены в течение 30 мин — обновляет.


        

            📋 Как настроить расширения
            

                
Feature 1 (авторизация панели + шифрование токенов):

                
PANEL_AUTH_USER=admin
PANEL_AUTH_PASS=mySecret123
TOKEN_ENCRYPTION_KEY=<ключ_сгенерированный_Fernet>

                
Сгенерировать ключ: python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"


                
Feature 2/3/4 (Twitch Helix API):

                
TWITCH_CLIENT_ID=<твоё_app_id>
TWITCH_CLIENT_SECRET=<client_secret>

                
Зарегистрировать приложение: dev.twitch.tv/console/apps


                
Feature 6 (прокси по умолчанию):

                
DEFAULT_PROXY=socks5://user:pass@host:1080

                
Также можно задать прокси индивидуально на каждый аккаунт в карточке аккаунта (кнопка ⚙).

        FAQ - Руководство по использованию
        

    
        
        
        
            
        Как начать?
        
            
          
                
        1. Перейди на twitchtokengenerator.com и сгенерируй OAuth-токен
          2. 
                
        2. Вкладка Аккаунты - нажми "+ Добавить аккаунт", введи ник и токен (формат: oauth:xxxxx)
          3. 
                
        3. Добавь каналы для подключения (поле "Добавить канал")
          4. 
                
        4. Нажми Запуск - бот подключится к Twitch IRC
          5. 
                
        5. Перейди на вкладку Чат - можешь отправлять сообщения
          6. 
            
        
        
        

        
        
            
        Вкладки
        
            
        
                
        Аккаунты - управление ботами. Добавляй аккаунты, каналы, запускай/останавливай.
        
                
        Чат - отправка сообщений, быстрые фразы, эмодзи, спам-режим.
        
                
        Логи - все сообщения в реальном времени. Можно искать по тексту.
        
                
        Паттерны - стиль общения AI. Задай system prompt и стиль ответов.
        
                
        Характеры - переключаемые "личности" бота. Можно создать несколько и активировать нужный.
        
                
        Триггеры - автоответы на ключевые слова. Можно использовать AI или фиксированный ответ.
        
                
        События - реакции на события Twitch (подписки, рейды и т.д.).
        
                
        Бан-лист - игнорировать сообщения от определённых пользователей.
        
                
        Фильтр слов - блокировка нежелательных слов в ответах бота.
        
                
        Анализ чата - авто-чат: бот сам читает чат и отвечает в тему через AI.
        
                
        AI Мозг - что AI "видит" и "думает". Логи всех запросов к модели.
        
                
        Настройки - выбор AI провайдера (Ollama/OpenRouter), модели, экспорт/импорт.
        
            
        
        
        

        
        
            
        AI Провайдеры
        
            
        
                
        Ollama (локально) - AI работает на твоём ПК. Нужно установить Ollama и скачать модель:
        
                
        ollama pull gemma2:2b    # лёгкая, быстрая (1.6 GB)
ollama pull llama3       # качественная, но тяжёлая (4.7 GB)
