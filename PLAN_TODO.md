## Для агента: как всё это устроено технически

Точные файлы, коммиты и имена тестов для каждого пункта из «Недавно сделано» — не здесь, а в
`git log --oneline` (сообщения коммитов написаны по одному на шаг) и в самом коде (комментарии
у изменённых мест ссылаются на нужный пункт, например `Q39` или `D1`). Для функций Режиссёра —
отдельная спецификация [`docs/specs/DIRECTOR.md`](docs/specs/DIRECTOR.md).

- Тесты гоняем только профильные: `.venv/bin/python -m pytest tests/test_<модуль>.py -q`,
  UI — `node --test tests/<имя>.test.js`. Полный `tests/` (~20 минут, тяжёлые ML-зависимости) —
  только по явной просьбе владельца.
- В этой песочнице перед pytest: `unset PYTHONPATH`.
- После правки Python-кода панель нужно перезапускать — в уже работающем процессе остаётся
  старый код.
- Ссылки во всех активных `.md`-файлах проверяются вручную: `python3 scripts/check_md_links.py`.
- Чеклист «точно всё готово» — [docs/PRODUCT_RULES.md](docs/PRODUCT_RULES.md) §3.
